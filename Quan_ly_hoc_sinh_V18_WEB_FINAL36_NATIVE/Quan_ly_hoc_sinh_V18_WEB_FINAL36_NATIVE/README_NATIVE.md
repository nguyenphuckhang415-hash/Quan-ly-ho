# QUAN LY HOC SINH V18 - WEB NATIVE

Bản này là chuyển đổi web native (Flask + HTML/CSS) dùng cùng SQLite/schema/luồng dữ liệu V18. File V18 gốc được giữ nguyên trong gói để đối chiếu.

Các nhóm chức năng web: đăng nhập 4 vai trò; đăng ký HS/PH; tài khoản HS/PH tự sinh duy nhất khi tạo mới/Excel; cập nhật lần đầu; duyệt HS/PH; lớp/tổ/nhóm; danh sách; điểm; nhiệm vụ; ban cán sự; sơ đồ; xếp hạng; tài khoản; QR; Excel; thêm HS; tổng kết; chat; nhắc hẹn; hồ sơ; đổi mật khẩu; mã xác nhận; xóa dữ liệu.

Triển khai Render: build bằng Docker, lắng nghe $PORT trên 0.0.0.0.
